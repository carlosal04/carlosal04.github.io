- **Production**: [www.basaltosyagregados.com](https://www.basaltosyagregados.com)

## 🔧 Local Development

1. Clone the repository:
```bash
git clone https://github.com/carlosal04/carlosal04.github.io.git
cd carlosal04.github.io
```

2. Serve locally:
```bash
# Using Python
python3 -m http.server 8080

# Using Node.js
npx http-server -p 8080
```

3. Open in browser:
```
http://localhost:8080
```
